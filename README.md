# Project Title:
Classic Café Corner – Sales Data Analysis Dashboard (Power BI)

# Introduction:
Developed an interactive Power BI dashboard for Classic Café Corner to analyze key KPIs, including total sales, profit margins, customer demographics, and product performance. The dashboard provides clear visual insights to support effective decision-making and business growth.

# Project Overview:
This project presents a comprehensive sales data analysis for Classic Café Corner using Power BI. The goal is to uncover actionable insights by analyzing key business metrics and visualizing them through an interactive dashboard. The report helps stakeholders monitor performance and make informed decisions efficiently.

#Key Insights & KPIs

The Power BI dashboard focuses on the following metrics:

Total Sales & Revenue Trends

Profit Margins & Cost Analysis

Customer Demographics (age groups, preferences, behavior)

Top-Performing Products & Categories

Sales by Region / Outlet (if applicable)

Monthly & Quarterly Sales Trends

# Dashboard Features

Interactive visualizations for deep data exploration

Slicers and filters for dynamic insights

Trend lines and comparison charts

Clean, intuitive, and user-friendly UI

Real-time decision-making support

# Tools & Technologies Used

Power BI Desktop

MS Excel / CSV Data Sources

DAX Measures for KPI calculations

Power Query for data cleaning and transformation
